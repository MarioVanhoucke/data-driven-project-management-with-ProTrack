# ProTrack — Project Scheduling and Control

ProTrack is a project scheduling and control application developed for research and educational purposes. It combines baseline scheduling, schedule risk analysis, and project control in a single environment, and is built to read and expand the [DSLIB](https://www.or-as.be/research/data/) empirical project database.

## Final Release: ProTrack 2014

This is the final version of ProTrack. The software is no longer actively maintained, and — as a legacy research tool — it is a bit buggy.

## ⚠️ A Word of Caution

Reading project data in ProTrack is easy, but adding new data is somewhat buggy, so be careful when doing so. Despite this, ProTrack remains a good tool for reading the existing empirical project data in DSLIB, and, with some care, for adding new projects to it.

## Download

Download the latest release (a `.zip` containing the ProTrack executable) from the [Releases](https://github.com/<your-username>/<repo-name>/releases/latest) section of this repository. Unzip it and run the executable. ProTrack is designed for Windows; if you are on a recent version of Windows, you may need to run it in compatibility mode.

## Data & Tools

- **DSLIB** — the empirical project database that ProTrack is built to read and expand: [www.or-as.be/research/data](https://www.or-as.be/research/data/)
- **Excel ↔ ProTrack converter** — to move project data between MS Excel and ProTrack format: [www.or-as.be/tools/protrack](https://www.or-as.be/tools/protrack/)

## Tutorial

New to ProTrack? Start with the free companion book *Dynamic Scheduling on Your Desktop*, a practical guide to using ProTrack for dynamic scheduling. Available (along with our other books) at [www.or-as.be/books](https://www.or-as.be/books/).

## Usage

1. Download and unzip the latest release from this repository.
2. Run the ProTrack executable.
3. Read *Dynamic Scheduling on Your Desktop* to get familiar with the software.
4. Use ProTrack to explore the DSLIB projects, or add your own project data (see the word of caution above).
